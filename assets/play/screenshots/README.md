# Screenshots (required for Play)

This folder is intentionally empty until **real device captures** exist.

Follow: [`release/SCREENSHOT_CAPTURE_GUIDE.md`](../../release/SCREENSHOT_CAPTURE_GUIDE.md)

Minimum for phone listing: **2** screenshots showing actual PocketBrain UI from a native build.

Naming example:
```text
01_home_light.png
02_marketplace.png
03_chat.png
04_workspace.png
```

Do not submit mockups that look like the app but were not captured from the binary.
